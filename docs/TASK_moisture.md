## เป้าหมาย
ใช้เครื่องวัด pF ที่ทำเสร็จแล้ว (`cap_meter`) วัดค่า C ของแผ่นคู่ขนานที่มีเมล็ดกาแฟอยู่ระหว่างแผ่น แล้วแปลงเป็นค่าความชื้น

```
กดปุ่ม → LED 200 ms → วัด C (256 รอบ) → εr = (C − C_STRAY) / (C0 − C_STRAY) → MC = a + b·εr → พิมพ์ผล
```

ผลลัพธ์ทาง Serial (ข้อ 3.5):
```
"TGR-17"
Moisture Level = 11.23 %

```

## งานโค้ด

  - env เดิม (`esp32s3-n16r8`, `calib`) ต้อง exclude `moisture.cpp` ใน `build_src_filter`
- [ ] `src/moisture.cpp` ใช้โครงเดียวกับ `main.cpp`
  - ปุ่ม GPIO2 (วัดตอนกด), LED GPIO48 200 ms, ไม่รับการกดซ้ำ, ถ้าวัดไม่ได้ให้ลองใหม่ภายใน 2.5 s
- [ ] **ไม่ใช้ NVS และไม่มีคำสั่ง Serial** ค่าทุกตัวเป็น `#define` บนสุดของไฟล์
- [ ] `SHOW_DEBUG 1` = พิมพ์ C และ εr เพิ่ม สำหรับหาค่าตัวแปร (ตอนส่งงานต้องเป็น 0)

## ตัวแปรที่ต้องตั้งและวิธีหาค่า

| ตัวแปร | ความหมาย | วิธีหาค่า |
|---|---|---|
| `CAL_GAIN`, `CAL_OFFSET` | แปลงเวลาชาร์จเป็น pF | มีแล้ว 0.94597 / −9.2602 จาก env `calib` (ปรับเทียบใหม่ถ้าแก้วงจร) |
| `C0_PF` | ค่า C ของกล่องเปล่า | ติดตั้งแผ่นและยึดสายตามจริง กล่องว่าง `SHOW_DEBUG 1` วัด 5 ครั้งแล้วเฉลี่ย |
| `C_STRAY_PF` | C แฝงของสาย | ตั้งเป็น 0 ได้ เพราะการปรับเทียบ a/b ดูดผลส่วนนี้เข้าไปเอง |
| `MC_A`, `MC_B` | MC% = a + b·εr | เทเมล็ดที่รู้ความชื้นให้เต็มช่องแล้วปาดผิวเรียบ วัด εr 5 ครั้ง ทำ ≥ 2 ระดับความชื้น แล้วใช้ Excel `SLOPE()` = b, `INTERCEPT()` = a |

แผนสำรองถ้าไม่มีเมล็ดที่รู้ค่า: สมมติค่า b ไว้ก่อน แล้วปรับ a ให้ตัวอย่างอ่านได้ประมาณ 11% (สารกาแฟปกติชื้น 10–12%)

วิธีทำตัวอย่างความชื้นเอง (ใช้สารกาแฟที่ซื้อมา **ห้ามใช้ตัวอย่างที่ต้องคืน**):
- พ่นน้ำหรือตากแดด ชั่งมวลก่อนและหลัง แล้วปิดถุงทิ้งไว้ข้ามคืน
- `MC_ใหม่ = 1 − (1 − MC₀) × m₀ / m_ใหม่`

## ตัวเซนเซอร์
- PCB ทองแดงด้านเดียว 2 แผ่น ขนาด 10 × 5 cm วางแนวนอน (ยาว 10 สูง 5)
- แผ่นนอก = GND (ทำหน้าที่โล่), แผ่นกลาง = Vc, ช่องที่เหลือเว้นว่าง
- ทองแดงหันเข้าหากัน d = 1.00 cm ตามทฤษฎี C0 ≈ 4.43 pF (ค่าจริงจะสูงกว่าเพราะ fringing ให้ใช้ค่าที่วัดได้)
- ติดสติกเกอร์ทับทองแดงกันกระแสรั่วผ่านเมล็ดชื้น **ต้องถามกรรมการก่อนว่าใช้สติกเกอร์แบบนี้ได้ไหม**
- บัดกรีที่มุมบน สาย Vc สั้น 3–5 cm และยึดให้แน่น **ห้ามขยับหลังวัด C0 แล้ว**
- ปริมาตรช่อง 1 × 5 × 10 = 50 cm³ ใส่เมล็ดได้ประมาณ 30–35 g ตัวอย่าง 70 g จะล้น จึงต้องเทให้เต็มช่องแล้วปาดผิว (ใช้ปริมาตรคงที่แทนมวลคงที่)

## สิ่งที่ต้องทำเองที่หน้างาน
1. ซ้อมเทด้วยข้าวสารหรือถั่ว 5 รอบ εr ควรแกว่งไม่เกิน ±2%
2. ได้เมล็ดวันที่ 18 พ.ย. ต้องคืนวันที่ 19 พ.ย. 16:00 น. → ต้องวัด C0 และเก็บจุดปรับเทียบให้เสร็จก่อนคืน
3. ปรับเทียบในห้องเดียวกับวันแข่ง เพราะอุณหภูมิมีผลและไม่มีเซนเซอร์อุณหภูมิในชุด
4. ถามกรรมการ: (ก) ใช้เครื่องวัดความชื้นมาตรฐานก่อนวันแข่งได้ไหม (ข) วันแข่งใช้ตัวอย่างไหน 70 g หรือ 30 g (ค) ใครเป็นคนเทเมล็ด
