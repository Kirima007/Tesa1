# STATUS: TGR-17 · TESA Top Gun Rally 2026 Track 1 (อัปเดต 17 พ.ย. 2569)

เอกสารนี้ใช้ส่งต่อบริบทให้แชทหรือผู้ช่วยตัวอื่น โปรเจกต์อยู่ที่ repo `Kirima007/Tesa1` (PlatformIO)

## การแข่งขัน
- **18 พ.ย. 14:00–15:00:** ส่งเครื่องวัดตัวเก็บประจุระดับ pF (คะแนน 40%) ✅ โค้ดพร้อมส่ง
- **20 พ.ย. 11:00–12:00:** ส่งเครื่องวัดความชื้นเมล็ดกาแฟ (คะแนน 55%) ⏳ ยังไม่เริ่ม ดู [TASK_moisture.md](TASK_moisture.md)
- **ให้คะแนนจาก:** %Error ของค่าเฉลี่ย 5 ครั้ง, %RMSE และเวลาตอบสนอง (0–3 s ได้เต็ม)
- **กติกาที่ต้องทำตาม**
  - Serial 9600
  - ปุ่มกด 1 ครั้งแล้วปล่อย ถ้ากดซ้ำนับเป็นวัดพลาด
  - LED บนบอร์ดติด 200 ms ทุกครั้งที่กด
  - ห้ามใช้อุปกรณ์นอกชุดที่แจก
  - หลังส่งงานห้ามแก้โค้ดหรือฮาร์ดแวร์
- **อุปกรณ์ที่แจก:** LM393, VR 10k, R 1M / 10k / 2k อย่างละ 1 ตัว, C 5 / 10 / 15 / 20 pF และ 0.1 µF อย่างละ 1 ตัว, สวิตช์, สติกเกอร์ 2 แผ่น, สายต่อวงจร

## ฮาร์ดแวร์ (ESP32-S3-DevKitC-1 N16R8, Arduino core 3.3.9 / pioarduino)

| สัญญาณ | การต่อ |
|---|---|
| CHARGE | GPIO4 → R1 1 MΩ → โหนด Vc (LM393 ขา 3) + Cx → GND |
| Vref | trimpot 10k → LM393 ขา 2 (ประมาณ 1.65 V) **ห้ามหมุนหลังปรับเทียบ** |
| SENSE | LM393 ขา 1 → GPIO1, pull-up **2k** ไป 3.3 V |
| ปุ่ม START | GPIO2 → GND, pull-up 10k ภายนอก + C 0.1 µF คร่อมสวิตช์ (debounce: ช่วยให้ค่านิ่งขึ้นมาก) |
| LED | RGB WS2812 บนบอร์ดที่ GPIO48 |
| Serial | ช่อง UART (`ARDUINO_USB_CDC_ON_BOOT=0`) ที่ 9600 |

## ซอฟต์แวร์

| env | ไฟล์ | หน้าที่ |
|---|---|---|
| `esp32s3-n16r8` (default) | `src/main.cpp` | **firmware สำหรับส่งแข่ง** วัด pF |
| `calib` | `src/calib.cpp` | หา gain/offset จาก C 5 / 10 / 15 / 20 pF (50 × 256 รอบต่อจุด) แล้วพิมพ์ค่าให้ copy |

- **`cap_meter.h/.cpp`**
  - วัดเวลาชาร์จด้วย `ESP.getCycleCount()` ภายใน critical section
  - รอคายประจุ max(3 ms, 8 × เวลาชาร์จครั้งก่อน), timeout 5 ms
  - เฉลี่ยเวลา แล้วคำนวณ `C = t / (R1·ln(Vcc/(Vcc−Vref)))` จากนั้น `C = gain·C + offset`
- **ค่าปัจจุบันใน `main.cpp`:** `CAP_SAMPLES 256`, `calGain 0.94597`, `calOffsetPf −9.2602`
- **การทำงานของ `main.cpp`**
  - วัดเมื่อกดค้างครบ 5 ms ต้องปล่อย 50 ms ก่อนรับการกดครั้งใหม่
  - LED เปิดผ่าน esp_timer และปิดเองหลัง 200 ms
  - ถ้าวัดไม่ได้จะลองใหม่ภายใน 2.5 s
  - `SHOW_DEBUG 0` สำหรับส่งงาน
- **ผลลัพธ์:** `"TGR-17"` ↵ `Capacitance = xx.xx pF` ↵ บรรทัดว่าง
- **ประสิทธิภาพ:** ตอบสนองประมาณ 0.8–0.9 s, เป็นเส้นตรงในช่วง 5–35 pF, ค่าแกว่งประมาณ ±0.01–0.04 pF
  - วัดได้สูงสุดประมาณ 6,800 pF แต่ถ้าเกินประมาณ 1,750 pF จะใช้เวลาเกิน 3 s
  - 0.1 µF (104) วัดไม่ได้
- **โมดูลอื่น:** `MqttManager`, `AnalogInput` อยู่ใน repo แต่ไม่ได้ใช้ ส่วน ADS1115 / NTC / psychrometer ย้ายไปไว้ที่ `_disabled/`
